# PhotoDepth 3D — Interactive Gaussian Splat Viewer

A minimal, high-performance local WebGL 3D Gaussian Splatting viewer tailored for scenes generated by Apple's official ML-SHARP repository.

---

## Technical Stack & Architecture

* **Renderer**: Three.js (`0.168.0`) + `@mkkellogg/gaussian-splats-3d` (`0.4.7`).
* **Packaging**: Self-contained ES modules with native browser `importmap` in `libs/`.
* **Zero Cloud**: Operates 100% locally on `127.0.0.1` with no external CDNs or cloud dependencies.
* **Coordinate Space**: Configured with `cameraUp = [0, -1, 0]`, looking towards `+Z` to match Apple's OpenCV coordinate conventions out of the box.

---

## Local Run Instructions

### 1. Start the Local Server
From PowerShell or Command Prompt:

```powershell
& "D:\Mgai\.venv\Scripts\python.exe" "D:\Mgai\viewer\serve_viewer.py" 8080
```

### 2. Open in Browser
Open your browser to:
[http://127.0.0.1:8080/](http://127.0.0.1:8080/)

The viewer will automatically fetch and render the active ML-SHARP inference output (`D:\Mgai\test_output\teaser.ply`) from the `/api/ply` endpoint.

## Navigation & Controls

| Action | Mouse / Trackpad Control |
| :--- | :--- |
| **Orbit / Rotate** | Left Click + Drag |
| **Pan** | Right Click + Drag *(or Shift + Left Click)* |
| **Zoom (Dolly)** | Mouse Scroll Wheel *(or Trackpad Pinch)* |
| **Reset View** | Click the **Reset Camera** button on the top panel |
| **Load Custom PLY** | Click **Open PLY** to select any local 3DGS file |

## Future Streamlit Integration (Phase 4)

In the complete PhotoDepth 3D application, this viewer can be embedded in Streamlit via `st.components.v1.iframe(src="http://127.0.0.1:8080/", height=650)`. 
When a new inference completes, Streamlit can signal the viewer or update the local output file directly.
